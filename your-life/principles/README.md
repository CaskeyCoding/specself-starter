# principles/ — H5

Your principles, one markdown file each (use `../../templates/principle.md`),
sorted into domain folders. This is the top of the horizons stack — everything
else ladders up to here.

## Domains

`core` `work` `relationships` `health` `money` `integrity` `learning` — sensible
defaults you should edit to fit your life. `core` is for cross-domain principles;
keep it small (a cap of ~10 is a good forcing function). A principle that primarily
lives in one domain stays in that domain's folder.

## Revealed vs aspirational

Each principle carries `kind: revealed` (backed by evidence of how you've
actually behaved) or `kind: aspirational` (who you want to be, not yet lived).
The files in this folder are the revealed set. Aspirational entries collect in
`../aspirational.md`, one singleton file of principle-shaped entries (see
`../../templates/aspirational.md`), until evidence graduates one into its own
file here as `kind: revealed`. **The gap between the two is the most valuable
signal this system produces — never let the agent collapse it.**

## Lifecycle

`draft → active → contested → retired`. Nothing is deleted; retired principles stay
for the audit trail. Every principle states its falsification criterion — what
evidence would force retirement. See `../../steering/methodology.md`.
