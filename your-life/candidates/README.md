# Candidate staging

Agent-drafted principles, goals, habits, and evidence links go in
`YYYY-MM-DD/<slug>.md`, using [`templates/candidate.md`](../../templates/candidate.md).
Record the source entries, persona, and session id in frontmatter. Keep every
candidate at `status: draft`; the human decides what to accept or rewrite.

Staging is separate from committed active corpus. It supplies neither active
references nor evidence for coherence checks. Validation checks provenance and
the candidate schema, not active-artifact requirements.

Draft content is private and ignored by default, like the rest of `your-life/`.
See [`AGENTS.md`](../../AGENTS.md#candidate-staging-and-local-history) for the
dated local commit boundary when the corpus is deliberately versioned.
