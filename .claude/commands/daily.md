description: Close the day — yesterday's evidence + today's intent. Writes a dated journal entry.
---

Run the SpecSelf **daily** tier in the **Journalist** lens. Read
`steering/cadence.md` (daily row) and `personas/journalist.md`. Honor `AGENTS.md`.

1. Briefly reflect yesterday's entry back: did intent match what happened? (Fact,
   not judgment.)
2. Capture today: one decision, one friction, one surprise, and the one thing that
   would make tomorrow count.
3. Write to `your-life/journal/<today>.md` via `templates/journal-entry.md`.
4. ~2 minutes. No synthesis — that's for weekly+. End by noting if a weekly review
   is overdue.
