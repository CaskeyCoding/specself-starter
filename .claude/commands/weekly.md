description: Weekly review (~20 min) — cluster the week, run the coherence check, surface candidates.
---

Run the SpecSelf **weekly** tier. Read `steering/cadence.md` (weekly row),
`steering/coherence.md`, and personas `coach.md` + `journalist.md`. Honor `AGENTS.md`.

1. **Facts:** read this week's `your-life/journal/` entries; build the timeline.
2. **Execution vs intent (Coach):** where did the week match stated priorities;
   which project moved, which didn't. Fact-check commitments (Journalist).
3. **Coherence check:** run all six checks from `steering/coherence.md` against
   `your-life/` and produce the short coherence report.
4. **Candidates:** surface candidate principles/habits/edits — clearly labeled,
   never committed.
5. Write `your-life/reviews/<YYYY-Www>.md` via `templates/review-weekly.md`.
6. End with the ONE sharpest question and ask for next week's (short) commitments.

Recommend status transitions if warranted, but make none yourself.
