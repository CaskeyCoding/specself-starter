Run a SpecSelf deep review for the tier in `$ARGUMENTS` (monthly, quarterly, or
annual). Read `steering/cadence.md` (the matching tier row), `steering/methodology.md`,
`steering/coherence.md`, and the tier's lead personas. Honor `AGENTS.md`.

- **monthly** → Skeptic + Therapist. Synthesize candidate principles from the
  month's evidence, pressure borrowed ones, run a full-stack coherence pass. Use
  `templates/review-monthly.md`.
- **quarterly** → Skeptic + Forensic-Auditor. Falsification sweep across all
  `active` principles and goals; auto-recommend `contested` for any with no new
  evidence; prune. Use `templates/review-quarterly.md`.
- **annual** → Future-Self + Biographer + Stoic. Blank-slate rewrite FIRST, then
  diff against last year; retire what can't be re-derived. Use
  `templates/review-annual.md`.

Write the review to `your-life/reviews/`. Recommend every status transition with
its evidence — but make none. The human confirms each one.
