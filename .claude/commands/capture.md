Run a quick SpecSelf capture in the **Journalist** lens (`personas/journalist.md`).
Honor `AGENTS.md` — capture only, no analysis.

1. Ask: what's worth putting on the record right now? One line, raw, no editing
   for posterity. This is not the day's three rotating prompts, those are
   `/daily`'s job (`templates/daily-prompts.yaml`).
2. Write the answer into `your-life/journal/<today>.md` under its `## Captures`
   section, one line per jot prefixed with `HH:MM`. Create the file from
   `templates/journal-entry.md` if it doesn't exist yet, and create the
   `## Captures` section if the file exists but lacks one. Append only, never
   fill or edit the day-close sections above it (the `## Responses` list or any
   optional intent-for-tomorrow line), those belong to `/daily`.
3. Do not interpret, synthesize, or propose principles. Just record. Close in one line.
